# Заметка по QRC: ограничения реализации

Дата: 2026-05-13
Зафиксировано в согласии с пользователем (см. этап 1 аудита).

## Что реализовано

`src/rc_bench/core/reservoirs/qrc_service.py` — **классическая mean-field симуляция Ising-системы**, не настоящая унитарная эволюция квантового состояния.

Уравнение обновления:
```
x(t) = tanh(J · x(t-1) + h_in · u(t))
```
где `x ∈ [-1, 1]^N` — mean-field магнетизации (приближение `⟨σ_z_i⟩`), `J` — симметричная Ising-матрица связи с нормированным спектральным радиусом, `h_in` — поперечное поле.

К этому добавлена техника **virtual nodes** (Fujii & Nakajima 2017): после input-driven шага выполняются `depth − 1` шагов свободной эволюции, состояния конкатенируются в признаковый вектор размерности `n_qubits × depth`.

## Чего НЕТ

1. **Унитарной эволюции:** нет `U(t) = exp(-iHt)`, нет state vector `|ψ⟩`, нет сохранения нормы `⟨ψ|ψ⟩ = 1`. Динамика чисто классическая, нелинейная.
2. **Корректной квантовой меры:** «измерения» — это просто компоненты mean-field вектора, а не ожидаемые значения паулиевских операторов на квантовом состоянии.
3. **Запутанности:** mean-field приближение не несёт корреляций — каждая магнетизация эволюционирует независимо, связанная только через детерминированную J.

## Почему оставлено как есть

- QRC введён в проект **как тестовый класс резервуара**, чтобы проверить, что унифицированный протокол сравнения (HPO + multi-seed + Ridge readout) применим к произвольному классу нелинейной динамики.
- Корректная реализация QRC требует state-vector симуляции (`O(2^N)` память) или симуляции через density matrices, что выходит за рамки feasibility-фазы ВКР.
- Литература по QRC расходится: разные авторы используют разные кодировки и наборы наблюдаемых. Стандарт пока не установлен.

## Как трактовать в тексте ВКР

- **Не называть** «Quantum Reservoir Computing» в чистом виде.
- Корректные формулировки:
  - «quantum-inspired reservoir» / «классический симулятор квантово-вдохновлённой динамики»
  - «mean-field Ising reservoir с техникой virtual nodes»
- При сравнении в таблице 4 эмпирического обзора (`reports/empirical_summary.md`) ставить **звёздочку** напротив QRC и в подписи указывать: «mean-field симуляция, не unitary; см. `audit/notes_qrc.md`».
- В главе 4.3 (skeleton `reports/section_4_3_skeleton.md`) явно перечислить ограничения этого пункта.

## Что НЕ надо делать

- Не приводить численные результаты QRC как сравнимые с экспериментальными работами по реальным quantum RC (D-Wave, NMR-системы, photonic).
- Не интерпретировать `n_qubits` как реальное число кубитов — это просто размерность mean-field вектора.
- Не делать выводов о квантовом преимуществе на основе этих данных.

## Возможное продолжение (за рамками текущей задачи)

Если потребуется честная QRC-реализация:
- `qutip` или `pennylane` для state-vector симуляции малых систем (N ≤ 10).
- Кодирование: вход в гамильтониан как параметр поперечного поля `h(t) = h_0 + α·u(t)`.
- Эволюция: `|ψ(t+Δt)⟩ = exp(-iHΔt) |ψ(t)⟩`.
- Readout-признаки: `⟨ψ| σ_x_i |ψ⟩`, `⟨ψ| σ_z_i |ψ⟩`, корреляторы `⟨ψ| σ_z_i σ_z_j |ψ⟩`.
- Sanity check: `|⟨ψ|ψ⟩ − 1| < 1e-10`.
